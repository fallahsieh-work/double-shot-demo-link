## 1. 概述

一個靜態手機 HTML 頁面，透過 Google Publisher Tag (GPT) 嵌入單一 GAM 1x1 Ad Unit，供業務團隊做客戶提案展示使用。該 1x1 Ad Unit 的 creative 內部自帶完整互動邏輯，包含 4 個素材與動畫效果。

## 2. 目標

- 讓業務人員透過 URL 向客戶展示廣告版位效果
- 模擬真實手機瀏覽體驗（上下滑動長頁面）
- 快速部署、易於維護

## 4. Creative 互動流程（由 1x1 Ad Unit 內部控制）

```
【狀態 1：初始載入】
┌──────────────────────┐
│  素材 1               │  ← 寬度 100%，高度 auto（隨素材比例）
├──────────────────────┤
│     灰色佔位區塊      │
│     灰色佔位區塊      │
│     灰色佔位區塊      │
└──────────────────────┘

【狀態 2：用戶向下滑動，超過素材 1 範圍後觸發】
┌──────────────────────┐
│  素材 2（320x100）    │  ← sticky banner 固定螢幕頂端
├──────────────────────┤
│                      │
│  素材 3（130x130 GIF）│  ← 從螢幕頂部掉落至底部
│          ↓           │
│          ↓           │
└──────────────────────┘

【狀態 3：素材 3 落到底部後】
┌──────────────────────┐
│                      │  ← 素材 2 sticky banner 收起
│     灰色佔位區塊      │
│     灰色佔位區塊      │
├──────────────────────┤
│  素材 4（320x100）    │  ← 從螢幕底部向上滑出
└──────────────────────┘
```

> 以上互動動畫皆由 creative 內部邏輯控制，頁面端不需實作動畫。

## 5. 頁面結構（頁面端職責）

頁面只需提供：
1. 一個 GPT 1x1 廣告版位容器（放在頁面頂端）
2. 足夠長度的灰色佔位區塊（讓頁面可以上下滑動）

```
┌──────────────────────┐
│   GPT 1x1 Ad Slot    │  ← 頁面頂端，寬度 100%，無外層包裝
├──────────────────────┤
│                      │
│                      │
│   灰色佔位區塊（單一） │  ← 2000px 高，提供滾動空間
│                      │
│                      │
└──────────────────────┘
```

## 6. 假設

- 不需要後端 API 或伺服器
- 不需要用戶登入或互動功能
- 業務只需分享 URL 即可展示
- 客戶主要以手機瀏覽器觀看
- 灰色佔位區塊足以傳達版位配置效果
- Creative 內部會監聽頁面滾動事件來觸發狀態 2、3
- 頁面不需要額外的 JS 來配合 creative 互動

## 8. 風險與邊界條件

| 風險 | 影響 | 緩解方式 |
|------|------|----------|
| Creative 監聽滾動事件失敗 | 素材 2/3/4 不會觸發 | 確認 creative 在 iframe 內能否取得頁面 scroll 事件 |
| 1x1 Ad Unit 渲染為 1x1px | 素材 1 不可見 | 確認 GPT slot 的 CSS 不限制尺寸，允許 creative 展開 |
| 客戶用桌機開啟 | 版面走位 | 加入 viewport 限制或桌機提示 |
| GitHub Pages 有快取延遲 | 更新後客戶看到舊版 | 使用 cache-busting 參數 |
| SafeFrame 隔離 | Creative 無法操作頁面 DOM | 確認 GAM 設定是否啟用 SafeFrame，必要時關閉 |

## 9. 技術規格摘要

- 純靜態 HTML + CSS
- 引入 GPT JS SDK：`https://securepubads.g.doubleclick.net/tag/js/gpt.js`
- 單一 1x1 Ad Slot，放置於頁面頂端
- Ad Slot CSS 需允許 creative 展開（不設固定寬高限制）
- Mobile-first，viewport 設定為 device-width
- 部署：GitHub Pages（從 main branch）
